# Landon Curtis — Personal Portfolio

A complex, responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Included
- Multi-page portfolio: Home, About, Projects, Experience, Resume, Contact
- Dark/light theme with persistence
- Command palette (`Ctrl/Cmd + K`)
- Interactive terminal on the homepage
- Project filtering and detail modals
- Animated reveal effects
- Responsive mobile navigation
- Print-friendly resume
- Static contact form that prepares an email
- No framework or build step required

## Run locally
Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## Customize
- Replace placeholder GitHub/LinkedIn links in `contact.html`.
- Add a real email address to the contact workflow if desired.
- Add real screenshots under `assets/` and replace the CSS mockups.
- Update resume details as needed.

## Deploy
The folder can be uploaded directly to GitHub Pages, Vercel, Netlify, or another static host.
